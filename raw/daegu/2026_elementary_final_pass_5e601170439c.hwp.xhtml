회원가입(요약)

대구광역시교육연수원 홈페이지 주소 - http://edu.deti.or.kr

1. 대구광역시교육연수원 홈페이지에서 ‘회원가입’ 또는 ‘JOIN’을 클릭합니다.

2. 회원가입 절차는 [본인인증 〉 약관동의 〉 정보입력 〉 가입완료]입니다.

3. [휴대폰 인증하기] 또는 [아이핀 인증하기]을 선택하여 실명인증을 합니다.

가. [휴대폰인증] 선택 인증

1) 통신사 선택 후 이름, 생년월일, 휴대폰번호, 보안숫자를 입력합니다.

2) 휴대폰으로 전송된 [인증번호]를 화면에 입력하여 인증합니다.

나. [아이핀(I-PIN)인증] 선택 인증

[회원가입여부확인 〉 미가입 〉 아이핀 인증] 순으로 인증합니다.

Ⅰ/ 회원가입 방법 ※ 원활한 회원 가입을 위해 필독해주시기 바랍니다.

1. 대구광역시교육연수원 홈페이지에서 회원가입을 클릭합니다.

2. 휴대폰인증 또는 아이핀(I-PIN)인증을 선택하여 실명인증을 합니다.

가. <아이핀 인증하기> 선택 시

1) 신규발급 후 또는 기존에 발급받은 아이핀 ID, 비밀번호와 문자 입력 후 ‘확인’ 클릭

나. <휴대폰 인증하기> 선택 시

1) 통신사 선택 후 이름, 생년월일, 휴대폰번호, 보안숫자를 입력합니다.

2) 휴대폰으로 전송된 [인증번호]를 화면에 입력하여 인증합니다.

3. 인증이 끝나면 약관동의 창에서 동의함을 선택 후 회원가입 버튼을 클릭합니다.

4. 회원정보를 입력(빨간 * 은 필수사항) 후 가입 완료가 됩니다.

5. 화면 상단의 기본정보 입력 화면에서 필수 항목(*)들을 입력합니다.

SMS 수신에서 수신함을 클릭합니다.

(수신동의를 하지 않을 경우 연수 관련 안내 정보를 제공받지 못함)

6. 화면 하단의 기관정보 입력에서는 교육대상자 구분은 초등교사, 소속기관명과 근무기관명은 근무기관검색 버튼, 직급명은 직급검색 버튼, 직위명은 직위검색 버튼을 눌러서 입력합니다.

가. 나이스 정보 전송 : 동의안함 클릭하여 가입, 추후 발령 후 나이스 번호 부여 받으면 동의로 변경

나. 근무기관명 : 임용예정교사는 현재 근무하고 있는 기관이 없으므로 ‘대구-기타’ 검색 후

‘대구-기타학교’ 선택

다. 직급명 : 검색란에 ‘신규교사임용예정자’ 입력 후 ‘검색’ 버튼 클릭 ⇒ ‘신규교사임용예정자’ 선택

라. 직위명 : 검색란에 ‘교사’ 입력 후 ‘검색’버튼 클릭 ⇒ 교사(초등) 선택

7. 모든 항목을 입력하신 후 화면 마지막의 회원가입 버튼을 클릭합니다.

Ⅱ/ 수강신청 방법

1. 대구광역시교육연수원 홈페이지(http://edu.deti.or.kr)에 접속 후 화면 상단의 로그인 버튼을 클릭합니다.

2. 회원 가입 시 입력한 아이디와 비밀번호를 입력한 후, 로그인 버튼을 클릭합니다.

3. 로그인 후 수강 신청 버튼을 클릭합니다.

4. 과정 명에 “신규”를 입력 하고 검색 버튼을 클릭합니다.

5. 과정명 『2026 초등 신규임용예정교사 역량강화 직무연수』의 학교급(유치원/초등/중등)을 잘 확인하고 신청하기 버튼을 클릭합니다.

6. 유의사항 동의에 동의함 체크 후 신청 버튼 클릭

7. ‘과정 수강 신청이 완료되었습니다’ 라는 확인 메시지 후, 신청 완료 화면을 확인할 수 있습니다. ※ 원격 연수 콘텐츠(30시간)는 과정 담당자의 승인 후,

2026. 2. 6.(금)부터 [홈페이지 메뉴-나의 학습방-수강과정]에서 수강하실 수 있습니다.
